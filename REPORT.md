# Отчёт по заданию 4

## Цель
Разработать приложение, упаковать его в Docker и опубликовать на GitHub.

## Приложение
Список задач с добавлением, изменением статуса и удалением записей.

## Технологии
Python, Flask, Gunicorn, SQLite, Docker и Docker Compose.

## Упаковка
Dockerfile устанавливает зависимости из requirements.txt.
Gunicorn запускает приложение на порту 8000 контейнера.
Docker Compose перенаправляет порт 8088 компьютера на порт 8000.

## Данные
База SQLite находится по пути /app/data/tasks.db внутри контейнера.
Каталог подключён к именованному хранилищу tasks-data.

## Проверка
К отчёту прилагаются скриншоты запуска приложения, добавления,
изменения статуса и удаления задач, а также проверки сохранения
данных после пересоздания контейнера.
